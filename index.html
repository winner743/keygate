How to set it up
1

Publish your website (one time)

Open the GitHub token page, keep public_repo ticked, generate the token, paste it below and press Publish website. Wait until it says your website is live (1 to 2 minutes).

2

Create your share link

Pick a gate style, add a title and your Lua script, then press Create share link. No sponsor account or dashboard needed — the gate is KeyGate's own page.

3

Use the Lua script

Copy the ready-to-use script and run it in your executor. It shows the key menu and runs your script after a valid key. Your executor needs loadstring.

4

Test it before you share

Press Make a test key, paste it into the key menu and check that your script runs. Then open your share link in another tab and go through the steps once.

5

Share the link

Post the share link anywhere. Visitors finish the steps, get a KFREE key and paste it into your key menu.

If something goes wrong

The link shows a 404 page
Wait 2 minutes after publishing. Check that the link starts with your github.io address and that the repository is public.
"PLS DO NOT BYPASSING THE STEP" appears but nobody bypassed
Stay on the page and let the countdown in step 3 finish on its own, then press the button once it lights up. Use a normal browser tab, not a preview window. The small detection code under the message tells you the reason.
The key menu says Invalid key
Paste the whole key, including KFREE-. Keys last 24 hours. The script and the share link must come from the same Create step, because each one has its own secret.
Nothing happens after the key is accepted
Your executor must support loadstring. Check the console for lines starting with [KeyGate].
Strange text like <p style=...> appears
That comes from pasting out of a rich text editor. Paste as plain text. The token, the sponsor link and the script boxes clean it automatically.

Publish your website

Paste a GitHub token once. KeyGate creates a public repository and turns on GitHub Pages for you, so your share links live on your own permanent website.

  1. Open the GitHub token page.
  2. Keep public_repo ticked, press Generate token and copy it.
  3. Paste it below.

The token is only used in this browser to publish. It is never saved and never put in your links. You can delete it on GitHub afterwards.
